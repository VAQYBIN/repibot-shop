# Продающий лендинг

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** заглушка «Магазин ещё готовится» заменяется страницей, которая объясняет услугу, показывает живые тарифы и ведёт к покупке.

**Architecture:** страница собирается на сервере — цены и тексты должны попадать в HTML. Тарифы забираются через `fetchFromApi`; первый экран меняет главную кнопку в зависимости от того, есть ли активный триальный тариф. Интерактив вынесен в маленькие клиентские островки, остальное — серверная разметка.

**Tech Stack:** Next.js 16, React 19, `@repibot/ui`, vitest.

### Task 1: Первый экран

**Files:**
- Create: `frontend/apps/web/src/components/landing/hero.tsx`
- Create: `frontend/apps/web/src/components/landing/hero.test.tsx`

**Interfaces:**
- Produces: `LandingHero({ hasTrial }: { hasTrial: boolean })`.

**Поведение.** `hasTrial === true` — главная кнопка «Попробовать бесплатно» ведёт на `/register`; `false` — «Выбрать тариф» ведёт на `/plans`. Вторая кнопка всегда «Смотреть тарифы» на `/plans`. Заголовок — `<h1>` кеглем `text-display`.

Почему так: лендинг не должен обещать пробный период, если администратор его выключил. Ровно ради этого тарифы берутся живыми, а не переписываются в текст.

`frontend/apps/web/src/app/(public)/page.tsx`:

```tsx
import {
  LandingPlans,
  type PublicPlan,
} from '@/components/landing/plans-section'
import { LandingFaq } from '@/components/landing/faq'
import { LandingHero } from '@/components/landing/hero'
import { LandingReasons } from '@/components/landing/reasons'
import { LandingSteps } from '@/components/landing/steps'
import { fetchFromApi } from '@/lib/server-api'

/**
 * Главная.
 *
 * Тарифы забираются на сервере: цена, не попавшая в HTML, не попадёт ни в
 * выдачу поисковика, ни в превью ссылки — а это два места, где страницу
 * впервые видят.
 */
export default async function HomePage() {
  const plans = await fetchFromApi<PublicPlan[]>('/api/plans')
  const hasTrial = (plans ?? []).some((plan) => plan.is_trial)

  return (
    <main className="mx-auto flex w-full max-w-5xl flex-col gap-20 px-6 py-16 sm:gap-24 sm:py-24">
      <LandingHero hasTrial={hasTrial} />
      <LandingReasons />
      <LandingSteps />
      <LandingPlans plans={plans} />
      <LandingFaq />
    </main>
  )
}
```
